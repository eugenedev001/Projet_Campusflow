# CampusFlow

Application mobile de suivi des cours, des échéances et des tâches d'un étudiant, construite pas à pas au fil des 7 séances du cours de Programmation mobile (Master 1, M. Moctar Compaoré, 2026-2027).

**Auteur :** Ouedraogo Eugene Golbert


## Organisation du dépôt

| Dossier | Contenu | Séances |
|---|---|---|
| `docs/seance1/` | Fiche comparative, autopsie de BlackBerry, décision de plateforme | 1 |
| `docs/seance2/` | Persona, parcours, wireframes, design system v1 | 2 |
| `campusflow_models/` | Package Dart : modèles Task, Course, User et tests | 3 |
| `campusflow_app/` | Application Flutter | 4 à 7 |
| `server/` | `db.json` pour json-server (API simulée) | 7 |
